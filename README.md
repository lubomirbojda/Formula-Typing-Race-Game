Semestrálna práca z predmetu C# a .NET.

Ide o typegame, kde hráč vyhrá ak jeho formula prejde cieľom ako prvá. Formula sa posunie, keď hráč správne trafí písmeno v slove.

Pokiaľ nastane chyba pri spustení aplikácie, môže byť chyba so súborom:   /Aplikácia/.config/dotnet-tools.json    - pravým na súbor -> vlastnosti -> odblokovať súbor. (niekedy nastane chyba pri sťahovaní sa súbor zablokuje)

Spustiť cez visual studio -> ako startup project nastaviť Menu a následne spustiť program.
